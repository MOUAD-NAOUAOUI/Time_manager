# Terms & Definitions

| Term | Definition |
| :--- | :--- |
| **Focus Session** | A continuous, tracked block of time dedicated to a single task with an active timer. |
| **Overtime Prompt** | The modal interface that triggers when a task's elapsed time exceeds its planned estimate. |
| **Constraint Scheduling** | Algorithmic placement of tasks into calendar slots based on priority, energy, and deadlines. |
| **Weekly Hour Map** | A 7x24 grid visualizing hourly activity (Green = Completed, Red = Incomplete, Grey = Empty). |
| **pgvector** | An open-source PostgreSQL extension providing vector similarity search. |
| **Token Bucket** | A rate-limiting algorithm implemented via Redis to prevent denial-of-service or API scraping. |
